# AGENTS.md

Personal rules that apply to every project.

## Writing to GitHub

When creating or editing an issue comment, a pull request comment, or a pull request description, always end the body with this signature:

```text
---
🤖 Generated with [OpenAI Codex](https://openai.com/codex/)
```

- Do not duplicate it when editing a body that already carries the signature.
- Do not put it in commit messages.

# CLAUDE.md

Personal rules that apply to every project.

## Writing to GitHub

When creating or editing an issue comment, a Pull Request comment, or a Pull Request
description, always end the body with this signature:

```
---
🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

- Do not duplicate it when editing a body that already carries the signature.
- Do not put it in commit messages — the `Co-Authored-By` trailer covers those.
